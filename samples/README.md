# Shembuj për demonstrim

Këto gjashtë imazhe dermatoskopike janë nga HAM10000 dhe shërbejnë vetëm për
demonstrimin edukativ të aplikacionit.

| Imazhi | Etiketa reale |
|---|---|
| ISIC_0025303 | mel — Melanomë |
| ISIC_0025937 | bkl — Lezion beninj i ngjashëm me keratozën |
| ISIC_0026092 | vasc — Lezion vaskular |
| ISIC_0027347 | nv — Nevus melanocitar |
| ISIC_0030555 | df — Dermatofibromë |
| ISIC_0032384 | bcc — Karcinomë bazocelulare |

Burimi: HAM10000 / ISIC, licenca CC BY-NC 4.0. Imazhet janë kopjuar nga
repository publik `miloszkrawczyk/melanoma-classifier`, i cili përdor të njëjtat
pesha dhe dataset.
